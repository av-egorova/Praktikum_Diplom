# Дипломный проект Яндекс Самокат

В проекте выполнены задания по **работе с базой данных** и **автоматизации тестирования API**.

## Работа с базой данных

В файлах 'task_1.sql' и 'task_2.sql' находятся SQL-запросы для:

-получения списка логинов курьеров и количества заказов в доставке;
-получения трек-номеров заказов и их статус.

## Автотест API

Автотест проверяет сценарий получения заказа по  **трек-номеру**:

1. Создается новый заказ.
2. Сохраняется трек-номер созданного заказа. 
3. Выполняется запрос на получение заказа по трек-номеру.
4. Проверяется, что запрос возвращает код ответа "200".

## Запуск автотеста

Для запуска автотеста используется 'pytest'.
